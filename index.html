01 EMBEDDED AI

GRAIL

Jul – Aug 2026 · Team of 4

Gesture-Controlled Robotic Hand with On-Device AI Inference

A vision-based robotic hand that turns hand-landmark data into motion. A custom dense neural network runs directly on an STM32H7 microcontroller.

PythonEmbedded CTensorFlowMediaPipeSTM32H7X-CUBE-AIKiCad
01 / INPUTCamera + MediaPipe21 hand landmarks
→
02 / INFERENCESTM32H7 + INT8On-device neural network
→
03 / OUTPUTRobotic handServo movement
Engineering details +
  • Trained a custom dense neural network on 21-point MediaPipe hand-landmark data and deployed it with X-CUBE-AI.
  • Used INT8 quantization to fit the model within 3 KB of RAM at 99.3% classification accuracy.
  • Migrated the architecture from ESP32 to STM32H7 and resolved firmware, pin-mapping, and data-quantization constraints.

Camera processing and landmark extraction run in Python; neural-network inference runs on the microcontroller.
